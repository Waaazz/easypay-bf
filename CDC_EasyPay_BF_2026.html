2. Contexte et objectifs
EasyPay BF est une plateforme qui fait le lien entre les parieurs (clients), les opérateurs de transaction (agents) et la direction (administrateurs). Elle permet aux clients de recharger leur compte sur des plateformes de paris ou de retirer leurs gains, sans avoir à se déplacer physiquement, grâce à un réseau d'agents locaux.
Objectifs principaux
  • Permettre aux clients de soumettre des demandes de dépôt ou de retrait depuis leur smartphone en quelques secondes
  • Donner aux agents un outil mobile pour gérer les commandes clients en temps réel (accepter, traiter, compléter)
  • Fournir à l'administration une vue globale des transactions, des volumes et des agents actifs
  • Garantir la traçabilité complète de chaque transaction avec un système de statuts
  • Sécuriser les accès par authentification OTP (code SMS) pour chaque utilisateur
3. Utilisateurs et rôles
RôleProfilAccès
Client Parieur souhaitant recharger son compte de jeu ou retirer ses gains via Orange Money Dépôt, Retrait, Historique des transactions, Tableau de bord personnel
Agent Opérateur local qui exécute physiquement les transactions pour le compte des clients Liste des commandes en attente, acceptation, traitement et clôture des commandes
Administrateur Gestionnaire de la plateforme — supervision globale et gestion des agents Tableau de bord KPIs, toutes les transactions, gestion et promotion des agents
Important : Un agent est promu depuis un compte client par l'administrateur. Il n'existe pas de processus d'inscription direct en tant qu'agent. L'authentification est identique pour tous les rôles : OTP par SMS.

6. Fonctionnalités détaillées par module
6.1 — Module Client
FonctionnalitéDescription détailléeStatut
Accueil & sélection Sélection de la plateforme de paris (1XBET, MELBET, BETWINNER) et saisie du montant via un pavé numérique interactif. Montants rapides prédéfinis (1 000, 2 000, 5 000, 10 000, 25 000, 50 000 FCFA). Affichage du calcul des frais en temps réel. ✓ Web
Dépôt (recharge) Formulaire de dépôt avec saisie de l'ID de compte sur la plateforme de paris. Sélection de l'opérateur mobile. Soumission de la demande → création transaction "en attente". Écran de confirmation avec référence de transaction unique. ✓ Web
Retrait (gains) Formulaire de retrait avec : ID de compte 1XBET/MELBET/BETWINNER, numéro Orange Money destinataire, nom du compte Orange Money, code de retrait généré par la plateforme de paris. Restriction Orange Money uniquement. Instructions détaillées affichées. ✓ Web
Historique Liste des 50 dernières transactions du client avec filtres par type (dépôt/retrait) et par statut (en attente, en cours, terminé, annulé). Affichage : montant, plateforme, opérateur, date, statut coloré. ✓ Web
Tableau de bord Vue personnelle : total dépôts, total retraits, nombre de transactions en attente, 5 dernières transactions. Statistiques globales du compte client. ✓ Web
Notifications push Notification envoyée au client quand sa commande est acceptée par un agent, et quand elle est marquée comme terminée ou annulée. Mobile
6.2 — Module Agent
FonctionnalitéDescription détailléeStatut
Tableau de bord Affichage en temps réel de toutes les commandes en attente (pending) et en cours de traitement (processing). Compteurs par statut. Filtres par onglet : Tout, En attente, En cours. Cartes de commandes extensibles avec détails complets. ✓ Web
Accepter une commande L'agent clique "Accepter" → statut passe de "pending" à "processing" → l'agentId est enregistré dans la transaction. La commande disparaît du pool général et est attribuée à l'agent. ✓ Web
Marquer terminé Après exécution physique de la transaction (envoi Orange Money, recharge compte), l'agent marque la commande comme terminée → statut "completed". Le client est notifié. ✓ Web
Annuler une commande L'agent peut annuler une commande avec saisie obligatoire de la raison. Statut → "cancelled". Note d'annulation enregistrée dans la transaction. ✓ Web
Alerte nouvelles commandes Notification push envoyée à tous les agents actifs dès qu'un client soumet une nouvelle demande de dépôt ou de retrait. Mobile
6.3 — Module Administrateur
FonctionnalitéDescription détailléeStatut
Dashboard KPIs 6 indicateurs clés : total des transactions, volume des dépôts (FCFA), volume des retraits (FCFA), transactions complétées, agents actifs, volume total. Graphique en barres des volumes sur les 7 derniers jours. ✓ Web
Gestion transactions Liste de toutes les transactions (100 max par requête). Recherche par nom client, téléphone ou ID de transaction. Filtres croisés par statut et par type. Affichage du volume total complété. ✓ Web
Gestion des agents Liste de tous les agents avec statut (actif/inactif). Statistiques d'agents. Recherche par nom ou téléphone. Actions : activer ou désactiver un agent instantanément. Promotion d'un utilisateur client en agent via son numéro de téléphone. ✓ Web
6.4 — Authentification
FonctionnalitéDescription détailléeStatut
Connexion OTP Saisie du numéro de téléphone burkinabé (+226). Envoi d'un code OTP à 6 chiffres par SMS via Firebase Authentication. Vérification du code avec délai de renvoi (60 secondes). Délai d'expiration géré automatiquement. ✓ Web
Création de profil À la première connexion, l'utilisateur saisit son prénom et nom. Un profil est créé automatiquement dans Firestore avec le rôle "client" par défaut. L'administrateur peut ensuite promouvoir l'utilisateur en agent. ✓ Web
OTP natif mobile Sur mobile, la vérification OTP Firebase utilise le système natif du téléphone (auto-détection du SMS sur Android, saisie manuelle sur iOS) — plus rapide et plus fiable que la version web. Mobile
